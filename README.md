# Beret for GFOS

The AmiCradle Team's port of Beret (Nigel Kilmer's 2011 puzzle platform
game of telekinesis) to GFOS: AmigaOS 3.2 with GFOpenUp, 68040/68060 +
FPU, on GFOpenUp's SDL 2. It ships as a release archive with an Installer
and as the GFOpenUp part Parts/Beret.

Upstream is fetched at build time (package/beret.lock); this repository
holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
